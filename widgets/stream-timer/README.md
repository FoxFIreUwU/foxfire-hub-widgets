# Таймер стрима

Пробный виджет для FoxFire Hub. Показывает крупными цифрами время, прошедшее с
момента открытия страницы — например, "сколько идёт стрим".

## Как использовать вручную (до реальной установки из FoxFire Hub)

1. Скачай `index.html` из этой папки.
2. В OBS: Источники → "+" → Браузер → укажи путь к скачанному файлу как локальный файл.
3. Настрой размер источника под свою сцену.

## Настройки

Настраивается через параметры адресной строки (пока FoxFire Hub не подключает
`configSchema` напрямую к запущенному виджету):

- `textColor` — цвет текста, например `%23ff0055` (это `#ff0055` в закодированном виде).
- `fontSize` — размер шрифта в пикселях, например `96`.
- `longFormat` — `true` для формата чч:мм:сс, `false` — только мм:сс.

Пример: `index.html?textColor=%23ff0055&fontSize=96&longFormat=true`

## Скриншоты

Положи сюда, в папку `screenshots/`, файлы `01.png`, `02.png` и т.д. — FoxFire Hub
автоматически подхватит их в галерею карточки виджета (см. корневой
`SYSTEM_WIDGET_STYLE.md`, раздел 1).
