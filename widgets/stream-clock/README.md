# Часы для стрима

Второй пробный виджет для FoxFire Hub. Простые цифровые часы с текущим временем
компьютера, на котором открыт браузерный источник в OBS.

## Как использовать вручную (до реальной установки из FoxFire Hub)

1. Скачай `index.html` из этой папки.
2. В OBS: Источники → "+" → Браузер → укажи путь к скачанному файлу как локальный файл.

## Настройки

- `textColor` — цвет текста, например `%23ffffff`.
- `fontSize` — размер шрифта в пикселях.
- `use24h` — `true` для 24-часового формата, `false` — для 12-часового с AM/PM.

Пример: `index.html?textColor=%23ffffff&fontSize=60&use24h=false`
