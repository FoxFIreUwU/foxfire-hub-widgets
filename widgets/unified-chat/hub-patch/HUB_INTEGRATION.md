# Подключение к Hub: локальный сервер + чтение YouTube без ключа

Виджет `unified-chat` 2.3.0 уже готов. Чтобы чат YouTube читался **без ключа** и ссылка для OBS
стала **постоянной http-ссылкой**, в самом Hub (репозиторий `foxfire-hub`, папка `src-tauri`)
нужны два новых файла и несколько строк в `main.rs`. Rust-файлы написаны без доступа к компилятору
и к живому YouTube — **не собирались и не запускались**, см. раздел «Что проверить».

## 1. Файлы
Скопируй в `src-tauri/src/`:
- `youtube_chat.rs` — чтение live-чата YouTube (неофициальный InnerTube-интерфейс, как в pytchat)
- `local_server.rs` — сервер `127.0.0.1:47821…47830`, раздаёт папки виджетов и отдаёт сообщения YouTube

## 2. Cargo.toml (`[dependencies]`)
```toml
reqwest = { version = "0.11", default-features = false, features = ["json", "rustls-tls"] }
serde = { version = "1", features = ["derive"] }
serde_json = "1"
regex = "1"
tokio = { version = "1", features = ["time"] }
tiny_http = "0.12"
```
Если какие-то из них уже есть — оставь свои версии.

## 3. main.rs
Уже сделано в поставляемой версии Hub (см. `foxfire-hub.zip`). Суть:
```rust
mod local_server;
mod youtube_chat;
// в Builder:
.setup(|_app| { local_server::start(); Ok(()) })   // start() без аргументов
.invoke_handler(tauri::generate_handler![
    /* … */ youtube_chat::yt_chat_poll,
    local_server::local_server_port,
    local_server::register_widget_dir   // интерфейс Hub сообщает серверу папку каждого виджета
])
```
Папки виджетов регистрирует сам интерфейс (`registerWidgetDir` в `widgetLaunch.ts`, вызывается при старте
и при запуске/копировании ссылки) — поэтому работает и с папкой установки, выбранной пользователем.

## 4. Ссылка для OBS
Кнопка «Скопировать ссылку для OBS» в settings.html сама ищет сервер (`/ping` на портах 47821–47830)
и копирует `http://127.0.0.1:<порт>/w/unified-chat/index.html`. Менять в Hub ничего не нужно.
Если хочешь, чтобы Hub сам подставлял ссылку — передай её в параметре `__obsUrl` (виджет его уважает).
Ссылка не меняется при правке настроек: `config.js` рядом с `index.html` виджет перечитывает раз в 2 секунды.
Hub должен быть запущен, пока идёт стрим (сервер живёт внутри него).

## 5. Что проверить (по порядку)
1. `cargo check` в `src-tauri` — я не мог собрать, возможны мелкие правки типов/версий.
2. Запусти Hub, открой в браузере `http://127.0.0.1:47821/ping` → должен вернуться `{"app":"foxfire-hub",…}`.
3. Открой `http://127.0.0.1:47821/w/unified-chat/index.html` — должен загрузиться виджет (не пустое окно).
4. Впиши свой Twitch-канал и канал YouTube **во время идущего эфира** — в шапке окна стримера у YouTube
   должно быть «эфир …» и зелёная точка.
5. Если у YouTube красная точка — текст ошибки покажет, что именно не нашлось (`INNERTUBE_API_KEY`,
   `ytInitialData`, …): это значит YouTube поменял страницу, править нужно `youtube_chat.rs`.
6. `cargo test` — там несколько тестов на разбор сообщений и путей.

## 6. Безопасность сервера
Слушает только 127.0.0.1; проверяет `Host` (защита от DNS-rebinding); отклоняет запросы с чужих сайтов
(`Sec-Fetch-Site: cross-site`), кроме `/ping`; выйти за папку виджетов через `..` нельзя.
В `config.js` лежит API-ключ (если ты его вписал) — именно поэтому чужие сайты не пускаются.
