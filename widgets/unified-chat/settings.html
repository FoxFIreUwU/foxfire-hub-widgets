Подключение

Достаточно вписать один раз — текущая трансляция находится автоматически. Video ID вводить не нужно.

Без ключа — Hub сам читает чат, ничего получать в Google не нужно (неофициальный способ, YouTube может его сломать). Чтобы это работало в OBS, вставляй ссылку из кнопки «Скопировать ссылку для OBS» (она вида http://127.0.0.1:…). API-ключ — официальный способ, нужен ключ ниже; он же служит запасным, если чтение без ключа не сработало.

Проверить ключ
Как получить ключ (5 минут)
  1. Открой console.cloud.google.com и создай проект (или выбери существующий).
  2. APIs & Services → Library → найди YouTube Data API v3 → Enable.
  3. APIs & Services → Credentials → Create credentials → API key.
  4. Скопируй ключ сюда и нажми «Проверить ключ». Лимит — 10 000 единиц в день на твой ключ.
  5. Необязательно: у ключа включи «Restrict key» → только YouTube Data API v3.

Заполняй, только если авто-поиск почему-то не сработал — тогда виджет использует именно этот Video ID и сам ничего не ищет.

Окно виджета

«Авто» — сам определяет: запущено внутри FoxFire Hub кнопкой «Запустить» → красивое стилизованное окно для тебя; вставлено ссылкой в источник «Браузер» OBS → обычный прозрачный оверлей для зрителей. Менять вручную нужно редко.
