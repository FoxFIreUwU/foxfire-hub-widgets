Подключение

Достаточно вписать один раз — внутри FoxFire Hub текущая трансляция находится автоматически и бесплатно. Video ID вводить не нужно.

Нужен только для чтения сообщений — как получить, см. README виджета. Без ключа YouTube-часть просто не подключится, Twitch продолжит работать.

Заполняй, только если авто-поиск почему-то не сработал — тогда виджет использует именно этот Video ID и сам ничего не ищет.

Окно виджета

«Авто» — сам определяет: запущено внутри FoxFire Hub кнопкой «Запустить» → красивое стилизованное окно для тебя; вставлено ссылкой в источник «Браузер» OBS → обычный прозрачный оверлей для зрителей. Менять вручную нужно редко.
